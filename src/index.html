01 / Comece pelo essencial

O que você faz, para quem e qual o próximo passo?

Essas três respostas ajudam a escrever o primeiro pedido. Não precisa complicar: descreva seu negócio e diga o que deseja que o visitante faça.

Ver um exemplo de pedido

“Crie uma página para minha padaria, voltada para os moradores do bairro, com nossos produtos e botão para entrar em contato.”

Depois refine um ponto de cada vez: título, cor, foto ou botão. No modo Demonstração, use os comandos disponíveis; pedidos livres pela OpenAI precisam de saldo da API.

02 / Encontre o formato

Escolha a página pelo seu objetivo.

Link da bio reúne caminhos. Landing page apresenta uma proposta. Página de vendas destaca uma oferta. Negócio local mostra serviços e contato.

Como escolher

Quer reunir redes, portfólio e contato? Comece com Link da bio. Quer apresentar um serviço e receber contatos? Escolha Landing page. Tem um produto ou curso? Página de vendas ajuda a organizar a oferta. Tem uma loja física? Negócio local aproxima seu público.

03 / Deixe com a sua cara

Um modelo é o ponto de partida.

No Explorar, veja páginas completas para diferentes negócios. Use um modelo, envie uma foto e experimente trocar o título e as cores pelo chat.

Comandos para testar sem créditos

“Altere o título para ‘Bem-vindo à minha página’.”
“Mude a cor principal para azul.”
“Use esta imagem no primeiro bloco.”

04 / Veja de perto

Experimente os dois tamanhos de tela.

No editor, alterne entre computador e celular. Veja se o título está legível, se a foto está bem enquadrada e se o botão deixa claro o próximo passo.

Como revisar

Faça uma alteração de cada vez. Se não gostar, use Desfazer. A página, a conversa e as versões ficam no Meu perfil, neste navegador. Para guardar uma cópia, baixe o HTML.
